# Freshness and faster first load

## Highlights

- **Freshness** (EN) / **Aktualität** (DE) at `/freshness`: hub for documents that need a review decision.
- One clear OK action (**Still current** / **Noch aktuell**) with next-check interval, or **Needs update**; no separate snooze action.
- Faster first load via route-level code splitting and deferred TipTap.
- Optional scheduled auto-scan (admin flag under **Platform → Freshness**) and a soft hub hint when high traffic meets aging content.

## For admins

- Configure org default interval and auto-scan under **Admin → Platform → Freshness**. Auto-scan stays off until you enable it; cron detail remains under Operations → Scheduler if applicable.

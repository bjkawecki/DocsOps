# Initial platform

DocsOps ships as a self-hosted documentation platform for organisations: scopes, documents with a publish workflow, and an app UI in English and German.

### Features

- Organisation structure with company, department, and team scopes, plus documents that move from draft to a published version.
- Block-based editing; the document title stays in metadata and appears as the reading heading, while the body structure starts at H2.
- App interface available in English and German via the locale preference.

### Fixes

- Saving the document title and other metadata no longer loses in-progress edits when the document refreshes.
- Reading view keeps clear spacing between the title and the first body heading.

## For operators

- Full stack via GitHub Release bundle and GHCR images (app, worker, frontend, Postgres, MinIO, Caddy).
- Object storage image is `pgsty/minio` (pinned release tag), not upstream `minio/minio` (community images discontinued). Existing volumes and `MINIO_*` env stay compatible.
- Pin installs with `DOCSOPS_VERSION=v0.1.0`. After a retag of the same version, run `docker compose pull` and recreate containers so digests refresh. Demo public update: `DOCSOPS_FORCE_BUNDLE=1 sudo -E docsops-demo update --version v0.1.0` (or plain `docsops-demo update`, which forces the bundle refresh).
- Early tags may be overwritten while the product is still in early development; prefer pinned installs when digests must stay stable.
- Demo seed (Musterwerk IT GmbH): one unit per scope, five roles, shared password when `DEMO_MODE=true` or after CSV re-seed. Demo login with role picker; mutating admin APIs return 403 in `DEMO_MODE`.
- Demo / VM lab host CLI `docsops-demo` (Landing + app, `/etc/hosts`, daily reset). Install:
  `curl -fsSL https://github.com/bjkawecki/docs-ops/releases/latest/download/docsops-demo | sudo bash`
  Client `/etc/hosts`: `<VM-IP> docsops.local demo.docsops.local`. See [install.md](../../docs/install.md) (VM-Lab).
- Compose overlays: `docker-compose.demo.yml` + `docker-compose.lab.yml` and `Caddyfile.lab`.
- Public landing SEO (`robots.txt`, sitemap, canonical/OG, FAQ JSON-LD, prerender) ships with the Landing dist in the bundle.
